Como adicionar outro editor

  1. Dono: abra github.com/animaplay/animaplay.github.io/settings/collaborators → Add people → digite o usuário GitHub da pessoa.
  2. A pessoa aceita o convite por e-mail.
  3. Ela cria um token em Settings → Developer settings → Personal access tokens com escopo repo.
  4. Ela entra em /admin/editor.html, cola o token e publica — o nome dela fica registrado como autora.
